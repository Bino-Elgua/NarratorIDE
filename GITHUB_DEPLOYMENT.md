## How to Use

### Clone & Setup

```bash
git clone https://github.com/Bino-Elgua/NarratorIDE.git
cd NarratorIDE
npm install
```

### Start Server

```bash
npm start
# Opens http://localhost:3000 with Phase 2 enhancements
```

### Try It Out

1. Type some JavaScript code
2. Wait 500ms
3. Watch thinking dots animate (● ● ●)
4. See narration fade in
5. Notice persona colors cascade
6. Hover over history (shimmer effect!)

### To Configure LLM

Edit `.env`:
```env
LLM_PROVIDER=claude
ANTHROPIC_API_KEY=sk-ant-...
```

Or use Ollama (free):
```env
LLM_PROVIDER=ollama
# Run: ollama serve (in another terminal)
```
